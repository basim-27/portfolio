## 👨‍💻 About the Project

**BASIM.** is my personal developer portfolio, designed to introduce who I am, showcase my technical skills, and share my journey as a frontend developer.

I'm continuously learning, experimenting with new technologies, and turning ideas into functional and visually engaging web experiences.

This portfolio reflects my approach to development: clean design, thoughtful interactions, responsive layouts, and continuous improvement.

## ✨ Features

- **Cinematic Introduction** — Animated opening experience with a skip option.
- **Modern UI Design** — Minimal, elegant, and visually engaging interface.
- **Smooth Scrolling** — Integrated Lenis scrolling experience.
- **GSAP Animations** — Scroll-triggered animations and interactive visual elements.
- **About Me** — Introduction and my development journey.
- **Technology Toolkit** — Overview of the tools and technologies I work with.
- **GitHub Integration** — Dynamically displays public GitHub repository data.
- **Learning Journey** — Highlights my approach to continuous learning.
- **Contact Section** — Easy ways to connect with me.
- **Fully Responsive** — Designed for desktop, tablet, and mobile devices.
- **SEO Foundations** — Meta tags, Open Graph metadata, robots.txt, and sitemap.xml.
- **Accessibility Support** — Semantic HTML, keyboard focus states, and reduced-motion support.

## 🚀 Run Locally

Want to explore or run this project on your computer?

**1. Clone the repository**

```bash
git clone https://github.com/basim-27/portfolio.git
```

**2. Open the project folder**

```bash
cd portfolio
```

**3. Open in VS Code**

```bash
code .
```

**4. Launch the website**

Open `index.html` in your browser or use the VS Code Live Server extension.

No build process or package installation is required.
