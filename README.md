## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/basim-27/portfolio.git
```

**2. Navigate to the project**

```bash
cd portfolio
```

**3. Open the project**

Open `index.html` in your browser or use the VS Code Live Server extension.
